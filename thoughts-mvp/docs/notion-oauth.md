# Подключение Notion через OAuth

Пользователь нажимает «Подключить Notion», разрешает доступ на стороне Notion и выбирает страницу по названию в Thoughts. Если Notion создаёт страницу из шаблона интеграции, Thoughts использует её сразу. Для отдельного проекта можно выбрать другую доступную страницу из того же списка.

## Настройка для владельца приложения

1. В [Notion Developer Portal](https://app.notion.com/developers/connections) создай OAuth-интеграцию с правами читать, добавлять и обновлять контент. Выбери OAuth-интеграцию, которую смогут авторизовать пользователи нужных рабочих пространств. При желании настрой публичный шаблон страницы Thoughts в параметрах интеграции.
2. Укажи HTTPS-адрес возврата, например `https://auth.example.com/notion/oauth/callback`. На том же адресе размести сервис OAuth. Он запускается из `thoughts-mvp` командой `npm run notion-oauth -w @thoughts/api`. Для сервиса задай `NOTION_OAUTH_CLIENT_ID`, `NOTION_OAUTH_CLIENT_SECRET`, `NOTION_OAUTH_REDIRECT_URI`, а также `PORT` и `HOST` по требованиям хостинга. Секрет хранится в окружении этого сервиса.
3. Направь HTTPS-прокси на отдельный OAuth-процесс. Он обслуживает только `/notion/oauth/*`. Не записывай query string callback и тела запросов в логи прокси. Ограничь частоту публичных запросов на прокси. Основной Thoughts API для этого подключения публиковать не нужно.
4. Укажи публичный адрес сервиса без пути в GitHub Actions variable `NOTION_OAUTH_URL` для APK и OTA. Для локальной сборки задай `EXPO_PUBLIC_NOTION_OAUTH_URL` в `apps/mobile/.env`. Следующая сборка или OTA покажет кнопку «Подключить Notion».
5. Проверь Android или iOS с тестовым рабочим пространством. Разреши доступ к одной странице, запиши мысль офлайн, верни сеть и открой синхронизированную копию из приложения.

Сервис обменивает код и обновляет токены через Notion API. Между браузером и приложением передаётся короткоживущий зашифрованный билет, привязанный к конкретному запуску приложения. Токены пользователя сохраняются в SecureStore после выбора страницы. Ручное подключение доступно для сборок без адреса OAuth и для существующих настроек.
