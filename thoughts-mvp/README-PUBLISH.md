# Thoughts MVP — GitHub publication

The complete text source of the Expo/React Native Web, Node API, SQLite, DeepSeek and Jev adapter MVP is present in this branch under `thoughts-mvp/`.

Run `npm install`, `npm test`, `npm run api` and `npm run web` from `thoughts-mvp/`. See `README.md` for setup, environment files and the voice-recognition privacy contract.

The `docs/preview.html` is a static design preview, not the running Expo app. PNG screenshots are included in the downloadable source archive provided in the ChatGPT conversation, but are not committed to this branch. The seven API tests passed locally; the real Expo build and microphone test remain unverified because npm registry access was unavailable in the build environment. API keys and local DB are not committed.

The branch intentionally leaves the existing repository default branch unchanged.
